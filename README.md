# Comparative Analysis of Mutual Fund Schemes — Kotak, SBI & ABSL

## Project Overview

This project presents a comparative performance analysis of three Equity-Linked Savings Scheme (ELSS) mutual funds: Kotak ELSS Tax Saver Fund – Direct Growth, Aditya Birla Sun Life (ABSL) ELSS Tax Saver Fund – Direct Growth, and SBI ELSS Tax Saver Fund – Direct Growth.

The study evaluates their historical returns, volatility, market sensitivity, and risk-adjusted performance to understand how the schemes performed relative to one another over a common five-year period.

## Objectives

- Compare the annualised returns of the three selected ELSS schemes.
- Evaluate investment risk using annualised standard deviation and beta.
- Assess risk-adjusted performance using Sharpe and Treynor ratios.
- Measure excess performance using Jensen’s Alpha.
- Compare the overall risk–return profiles of the selected schemes.

## Methodology

The analysis uses historical NAV data for the three mutual fund schemes and benchmark index data sourced from Investing.com. The risk-free rate was obtained from the Reserve Bank of India.

Daily returns were calculated from successive observations and used to evaluate the following performance measures:

- **Annualised Return:** Measures the annualised historical return generated by each scheme.
- **Annualised Risk:** Measures return variability using the standard deviation of daily returns.
- **Beta:** Evaluates each fund’s sensitivity to movements in the benchmark.
- **Sharpe Ratio:** Measures excess return per unit of total risk.
- **Treynor Ratio:** Measures excess return per unit of systematic risk.
- **Jensen’s Alpha:** Evaluates performance relative to the return expected under CAPM.

The calculations use 250 trading days for annualisation, as specified in the project methodology.

## Key Findings

The workbook and report present the following comparative results:

| Performance Measure | Kotak ELSS | ABSL ELSS | SBI ELSS |
|---|---:|---:|---:|
| Annualised Return | 14.72% | 9.52% | 19.18% |
| Annualised Risk | 13.91% | 13.07% | 13.37% |
| Beta | 0.3479 | 0.1999 | 0.3134 |
| Sharpe Ratio | 0.6802 | 0.3263 | 1.0416 |
| Treynor Ratio | 0.2720 | 0.2133 | 0.4442 |
| Jensen’s Alpha | 6.56% | 2.60% | 11.31% |

### Comparative Assessment

- **SBI ELSS:** Recorded the highest annualised return and the strongest results across the Sharpe ratio, Treynor ratio, and Jensen’s Alpha.
- **Kotak ELSS:** Ranked second in annualised return but recorded the highest annualised risk among the three schemes.
- **ABSL ELSS:** Recorded the lowest annualised risk and beta, alongside the lowest annualised return and risk-adjusted performance measures.

Based on the reported results, SBI ELSS demonstrated the strongest overall historical performance during the study period.
